Static file served by UseStaticFiles()

This page is a plain file at wwwroot/index.html. It reached your browser via app.UseStaticFiles() in Program.cs — no controller, no routing, no MVC was involved. The static-files middleware matched the request path to a file on disk and returned it directly.

Note: the app root / is redirected to /swagger by a MapGet in Program.cs, so open /index.html explicitly to see this page. See docs/ICONFIGURATION.md for how the middleware pipeline and IConfiguration fit together.
